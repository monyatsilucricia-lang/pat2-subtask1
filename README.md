# Morse Code

## What is Morse Code?

Morse code is a communication system used to represent letters, numbers and symbols using combinations of dots (.) and dashes (-). It was commonly used to send messages over long distances using telegraph systems.

## History of Morse Code

Morse code was developed in the 1830s by Samuel Morse and other contributors. It was created to make it possible to send messages over long distances using electrical signals through the telegraph. This allowed people to communicate much faster than sending physical messages.

## How Morse Code Works

Morse code uses two basic signals: dots and dashes. Each letter of the alphabet has its own combination of dots and dashes.

For example:

- A = .--
- B = -...
- C = -.-.
- D = -..
- E = .
- H = ....
- L = .-..
- O = ---
- S = ...

Letters can be combined to form words.
